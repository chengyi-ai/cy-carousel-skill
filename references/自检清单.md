# 自检清单

## 自动检查与人工审核分别留证

- [ ] 事实表完整：人物、日期、数字、引语回原页；传说限定词在正文；原件/著录/后世转述分开。
- [ ] 官方图片许可已保存，阅读权与复用权分开；同图同ID、没有拆ID凑15源。
- [ ] D主封面两行大标题；全套预览第一格D；C明确无字备选；系列书签默认关闭。
- [ ] 全部成品PNG1440×1920；照片/背景等比cover；透明抠图才contain；裁片/脸框/方法有记录。
- [ ] 成图与报告SHA一致；素材SHA与清单一致；报告对应当前配置和页面脚本。
- [ ] 文字始终最上层；抠图框碰撞≤3%；逐行贴条不挡脸；墨迹没有越界。
- [ ] 无缺字；实际补字另有审计；授权标题未回退；毛笔不含数字、标点贴住字。
- [ ] 暗篇清晰B，白色大字宋体700，彩色大字马善政；浅篇黑粗标题/轻影，正文58–64px。
- [ ] 全篇tone一致；暗篇无浅色平底；浅篇无黑底；局部背景渐变无硬矩形灰卡。
- [ ] 暗篇大字交替、上下1/3呼应、正文强调词≤1；每页面积≤3%、均值1.2–2.0%。浅篇按专用规则，无强调色均值下限。
- [ ] 浅篇空白≤38%、每页矩形主照片≥40%宽及柔影、确名人物角标、抠图≤1、红圈≤2、红毛笔≤3。
- [ ] 正式暗篇丰富度/来源/主角/骨架配额通过；浅色黑白档案不伪上色；局部用户例外保留理由与实测。
- [ ] 圆盘实心柔色、人物真抠图出边、柔影、可见面积≥40%，没有头像细圈。
- [ ] 封面主图再用时换明显不同裁切/特写，不能滑页重复构图。
- [ ] 原尺寸、缩略图、完整预览逐张目检，图注/断行/标题重音/脸和手的裁切均可读。
- [ ] 盲测3:4cover，无变形/黑边；随机种子和答案单存；封面只测D。
- [ ] 机器检查不等于视觉盲测或事实人工通过；账号占位、许可疑问、未验证点写待确认。
- [ ] 成品输出到新目录，不覆盖用户已定稿文件；没有上传/发布。
