# 历史选题

选题从可见的物件进入人的处境：服饰、首饰、家具、礼仪或社会规训。画面里有具体人物/动作，档案里有足够准确而意外的细节，冲突才站得住。

## 四道筛选

1. **证据**：至少一个可回读的可靠原始出处；关键数字/引语有页码。起源流传版必须能分级。
2. **人物**：有明确人物，或诚实的匿名人物场景；能讲动作和后果，而不只是知识定义。
3. **视觉**：有脸的封面图，8–12页能轮换人物、实物、档案，不靠重复四张图铺满。
4. **冲突**：美与代价、秘密与公开、规则与身体、身份与行动；强度来自事实，不凭想象加死伤数。

## 可迁移结构

|入口|查证问题|画面路线|
|---|---|---|
|一件流行服饰|谁制作、谁规定、哪些材料或动作有风险|佩戴者→作坊→原始记录→社会反应|
|一件私密首饰|身份、年代、赠送/起源是否只是传说|主物特写→人物关系→档案→意义|
|一条身体规则|地点、时间、签发者、对象及罚则是否有原文|动作特写→场景全景→文本→个人处境|

以上为自己的结构总结，不是参考作者选题清单或原文。新题保留证据边界，避免为了冲突把局部规定写成全国法律。
