# 例 04｜头上顶着一艘战舰（1778 年「美丽母鸡号」发式）

用排版器 `scripts/build.py` 做出来的完整一篇，是这套风格目前的标准样本。

![全套预览](全套预览.jpg)

## 文件

- `内容.json`：全部内容，包括封面、11 张内页的文字、选图、裁切和人脸框。版式、字号、断行都由排版器决定，里面没有一个坐标是手调的。
- `标题.txt`、`正文.txt`、`置顶评论.txt`：发布用的文稿。置顶评论逐页写明图源和证据边界。
- `素材清单.json`：用到的 17 个素材文件，以及每个文件的 SHA256。

## 重现

原图没有随包提供，都是公有领域或 CC0，可以按置顶评论里的出处下载。把下载的图放进 `assets/`，抠图用 `swift scripts/cutout.swift` 生成，路径按 `内容.json` 命名，然后运行：

```bash
python3 scripts/build.py examples/04-战舰发型/内容.json --out 工作/战舰发型
```

## 值得照抄的地方

- 每页都有一张看得清脸的当时人物图：肖像、版画或讽刺画。
- 标题两行。毛笔蓝色和白色宋体逐页交替；标题里有数字的页面，排版器会自动改用宋体。
- 正文每页 60–110 字，不手动断行也能断在语意处。人名和地名写进 `protect`，就不会被拆到两行。
- 图上没有图注、页码或页眉，出处全部放在置顶评论。
- 没有当年直接记录的说法，用「流传」「回忆录的说法」写出边界。
